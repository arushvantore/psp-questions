## What's inside

- **100/100** assignment + contest question texts (29 assignments,
  77 solved), with status, XP, deadlines, topics, playground URLs.
- **In-class quiz questions** under the lecture videos (read-only
  capture), plus post-class question text below each lecture video —
  14 of 32 lecture windows carry content.
- **9 quiz schedules** (titles/windows/XP).
- End page: **WHERE THESE QUESTIONS CAME FROM** and **NOT FETCHED**
  (what only the student can open manually: `Attempt Now` /
  `Start Test` items — 4 closed revision quizzes + Quiz Contests
  MCQs: PSP Contest 1, Wifi Demo, Demo_Contest, Mock Test).

## Using it with an AI tutor

Paste the raw markdown:

```
https://raw.githubusercontent.com/arushvantore/psp-questions/main/questions.md
```

and say e.g. *"teach me PSP from this"*. The end page tells the AI
exactly which sources are complete and which gaps it must not invent.
